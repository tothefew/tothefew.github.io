更换密码

前言

之前我为了图省事，很多社交平台的账号名和密码都是用的同一套模板，只是在它的基础上改动一两个字符罢了。

比方说我的密码模板是zhangsan6666，那么我的某信密码大概就是zhangsan7777这样的形式。

所以说只要有人知道了我的任意一个平台的密码，那么他也许能很轻易的破解我的“通用密码”，进而得到我的全平台密码。

由于我的懒惰和不知道哪里来的奇特的带有侥幸心理的想法“反正我的账号也没什么被盗的价值”，最近几年的注册的平台的密码设置一直如此随意。

为了一定程度上保护我的账号安全，最近终于下定决心对我所使用的平台进行手动批量密码更换。

呃，至少应该把它设置的复杂点儿。

过程

我把整个过程分成了四步：

  1. 打开我要更换密码的平台，点击修改密码，如果不记得了就找回密码。（不过还是有很多平台因为注册邮箱确实或忘记了密保问题，这个过程确实很费时费力，不过也发现了很多没用了的网站账号可以抛弃掉）

  2. 随便找个Password Generator，生成一串长密码（个人习惯16位往上），包含数字、大小写英文字母和特殊符号。（不过也要注意，比如有些网站的密码只支持字母数字和点，不支持特殊字符，需要擦亮眼睛）

  3. 找个你信得过的地方储存好它们。

  4. 整个过程其实并不难，只是需要更换的平台太多了谁叫你天天瞎注册一堆账号，自作自受了吧，这件事我断断续续地用了一个周来完成，据不完全统计，我至少更换了三十多个平台的密码。

在更换之前，我的这些平台共用同一套模板，如果模板泄露了，那后果不堪设想。

也是挺侥幸的哈，暂时还没有事。

设置2FA

什么是2FA？

双重认证 Two-factor authentication，缩写为2FA，又称为双重验证、双因子认证、双因素认证，也有叫两步验证2-Step Verification，是多重要素验证中的一个特例，使用两种不同的元素，基于时间随机生成一串验证码用于和服务器验证的技术，来确认用户的身份。

开启2FA可以有效提升账户安全性，避免因密码泄露而账户失窃。

开始设置

  1. 选择你喜欢的身份验证器。常见的身份验证器有Google Authenticator、2FAS、Authy、Aegis等等，不过我个人还是习惯用Aegis，也没什么特别的原因，仅仅是因为它比较美观。可惜Aegis只有安卓版本:)

  2. 以开启 Github 的2FA为例，用Aegis作为Authenticator。按照Settings>>Access>>Password and authentication>>Enable two-factor authentication的顺序，然后打开Aegis，点击右下角的+号，扫描Github提供的二维码或者手动输入Key，点击Save，最后输入Aegis提供的六位验证码即可完成2FA设置。

  3. 设置好后每次登录Github都需要使用两步验证，记得保管好你的备份二维码或文件哟！

补充：

新的措施

之前我写了篇文章（上文）来记录我更换密码和设置2FA的过程，其中提到了“妥善保管密码”，不过当时并未说明具体该如何保管。

因为我之前保管密码的方式一直是……放在切断了联网权限的系统便签中，并设置应用锁，然后需要时再复制粘贴，虽然相对比较安全，但总归不太方便，后来看到有人分享1password、Keepass（这里指 Keepass 全系列）之类的密码管理器，发现于是下载了 KeepassDX 并使用了几个月。

（之所以没从大名鼎鼎的1password开始，是因为这家需要订阅才能使用，而且订阅价格也是水涨船高……我的确需要一个安全、易用、可以跨设备同步的密码管理器，但为此付出每年几十美刀的费用还是难以承受的）

KeepassDX无需联网，数据完全储存在本地，安全性高，设计也较美观。说实话我是非常满意的，除了自动填充功能时不时失灵一下。不过在购入笔记本后有了跨设备同步的需求，Keepass系的本地存储方式就显得不够便捷了。

于是我开始把目光转向Bitwarden，又发现有大佬做出了cloudflare worker版的NodeWarden，无需服务器即可自托管Bitwarden，于是果断部署了一个。

使用一段时间发现效果还不错，自动填充比KeepassDX稍好一些，同步很方便，不过它的UI嘛……看起来蛮简陋的，功能当然也比不上1password全。不过总的来说，作为一款开源、可借助cf自部署的应用管理器，NodeWarden的使用体验还算是很不错的了。

不过一个不太方便的点是，Bitwarden本身不支持直接导入2FA验证器的备份文件，只能一个一个输入，数量多时极其麻烦，所以我还是在配合Aegis使用，这种需要切换两个应用的一次账号登录体验着实不算跟手。

结语

至此，我的账号“保险”之路才算是告了一段落，虽然还有通行密钥等更为安全的方式没有体验过，但就目前阶段而言，这些措施也算足够了。

不过账号安全是一个长期命题，也许定期更换密码、坚决不使用相似密码、不直接复制密码到剪贴板等“小行为”才能够让这段路走得更远。
